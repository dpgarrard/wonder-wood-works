# Wonder Woodworks

A multi-page static website built for **Wonder Woodworks**, a small, family-owned custom woodworking business.

## Overview

This project showcases a clean, responsive web layout created as part of a web page development course (`CIT 155`). The site highlights the company's craftsmanship, customer-first approach, product offerings, and ordering process.

## Features & Structure

- **Navigation Bar:** Quick links across the main sections of the site:
  - **Home** (`wonder woodworks index.html`): Landing page featuring a hero banner image, brand introduction, and core value propositions.
  - **Products**: Catalog of custom woodworking items and pieces.
  - **Order Info**: Details on placing custom orders, warranty coverage, and customer communication.
- **Business Highlights:**
  - Custom orders of all sizes
  - Attention to detail and wood grain quality
  - Continuous communication throughout the build process
  - Warranties included on all finished pieces
  - Fully insured, family-owned operation
- **Contact & Footer:** Displays the business address (`31 Spooner St, Quahog, RI 95555`), phone number (`888-555-5555`), copyright notice, and direct email contact (`dan@garrard.com`).

## Technologies Used

- **HTML5:** Semantic structure for headers, navigation, lists, and footer content.
- **CSS3:** Custom styling for typography, color palette (forest green header/navigation, warm accents), and layout alignment.

## Getting Started

To view the project locally:

1. Clone or download this repository to your machine.
2. Navigate to the project folder.
3. Double-click `wonder woodworks index.html` (or right-click and select **Open with** your preferred web browser).
